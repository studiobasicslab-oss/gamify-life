# Gamify Your Life 🎮✨

A cozy, retro 8-bit RPG life & task tracker built as a **Progressive Web App (PWA)**. 

Inspired by the retro game poster, it turns everyday habits, learning, and self-care into real XP gains, levels, and reward unlocks—completely **offline, private, with zero logins and zero cloud**.

---

## 🚀 Quick Start

1. Start the dev server:
   ```bash
   npm run dev
   ```
2. Open in your browser:
   - **On your computer**: [http://localhost:5173](http://localhost:5173)
   - **On your mobile phone** (same Wi-Fi): Open the Network URL shown in the terminal (e.g. `http://192.168.0.x:5173`)

3. **Install as App (PWA)**:
   - **iPhone / iPad**: Open in Safari → Tap **Share** (📤) → Tap **"Add to Home Screen"**.
   - **Android**: Open in Chrome → Tap **"Install App"** banner or Menu (⋮) → **"Install App"**.
   - **Mac / Windows**: Click the **"Install App"** button at the top of the webpage or browser address bar install icon.

---

## 🌟 Key Features

1. **Choose Your Character**:
   - Customizable pixel heroes (Unicorn Knight, Brave Warrior, Cosmic Mage, Forest Scout, Cozy Adventurer, Cyber Rogue).
   - Set custom hero name & title.

2. **RPG Stats System**:
   - 7 core life attributes: **Knowledge, Health, Focus, Creativity, Social, Discipline, Kindness**.
   - Segmented pixel progress bars with stat level progression.
   - Ability to add your own custom stats.

3. **Earn XP (Instant Quick Actions)**:
   - 10 preset quick actions (+Study, +Exercise, +Read, +Practice, +Help, +Drink Water, +Wake Up Early, +Stay Focused, +Try Something New, +Take Care of Yourself).
   - Instant floating `+XP` particle animations and 8-bit sound effects.
   - Add custom daily actions anytime.

4. **Level Up Progression**:
   - Every milestone unlocks the next level.
   - Fanfare chime + pixel confetti celebration modal on level up!

5. **Quests & Missions**:
   - Stylized RPG parchment quest board.
   - Daily and weekly missions with XP + Gold rewards.
   - Add new custom quests and check them off.

6. **Rewards Shop**:
   - Spend Gold earned from quests to reward yourself (Watch a movie, enjoy a treat, play a game, take a break).

7. **Track Progress & Daily Reflection**:
   - Pixel art landscape painting that says *"KEEP GOING!"*.
   - Interactive **Daily Treasure Chest** (click to open once a day for bonus XP & Gold).
   - Daily reflection prompts: *"What did I improve today?"* and *"Tomorrow's main quest"*.

8. **Retro "Save Cartridge" Memory Card**:
   - 100% offline local storage in browser database.
   - **Cross-device capability without cloud**: Click **"Save Card"** to export `savefile.json` and restore it on any phone or laptop.
   - Built-in Web Audio API 8-bit chiptune synthesizer (sound toggleable anytime).
